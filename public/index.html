什么是 SSR（服务端渲染）？

SSR（Server Side Rendering，服务端渲染）是一种网页渲染方式。与传统的客户端渲染（CSR）不同，SSR 会在服务器端将页面内容渲染成 HTML 后直接返回给浏览器，浏览器收到后即可直接展示页面内容。

SSR 的优点

  • 更快的首屏加载速度：用户打开页面时，能立即看到完整内容，提升用户体验。
  • 更好的 SEO：搜索引擎可以直接抓取到完整的 HTML 内容，有利于网站收录和排名。
  • 更好的分享体验：社交平台抓取页面时能获取到完整内容和预览图。

SSR 的缺点

  • 服务器压力大：每次请求都需要服务器渲染页面，服务器负载较高。
  • 开发复杂度提升：需要同时处理服务端和客户端的代码，调试和部署更复杂。
  • 部分交互需二次加载：页面首次渲染后，仍需客户端 JS 接管页面，实现完整交互。

常见的 SSR 框架

  • Next.js（React）
  • Nuxt.js（Vue）
  • Remix（React）
  • Angular Universal（Angular）

SSR 适用于对 SEO 要求高、首屏加载速度要求快的场景。选择 SSR 还是 CSR，需要根据项目实际需求权衡。
